## English

A comprehensive, interactive web-based dashboard designed for engineering and construction project management. This tool helps project managers, QA/QC engineers, and coordinators track and monitor Non-Conformance Reports (NCR) and Site Observation Reports (SOR).

### 🚀 Key Features
* **Status Tracking:** Monitor active, rejected, overdue, and escalated items.
* **Discipline Breakdown:** Visualize items across different engineering disciplines.
* **Root Cause & Priority Analysis:** Identify systemic failures instantly.
* **Interactive Register:** View and filter logs dynamically.

### 📋 Item Classification
Items are automatically categorized based on their impact:
* **Critical:** Structural, safety, or fire risks that block operations (e.g., cut rebar, missing fire protection).
* **High:** Major breaches of contract, specifications, or codes (e.g., unsuitable backfill).
* **Medium:** Deviations that can be resolved without affecting the project schedule (e.g., minor oil leaks).
* **Low:** Cosmetic or documentation issues only (e.g., missing labels).

## العربية

لوحة تحكم تفاعلية شاملة مخصصة لإدارة المشاريع الهندسية والإنشائية، مصممة لمساعدة مدراء المشاريع ومهندسي الجودة (QA/QC) في تتبع ومراقبة تقارير عدم المطابقة (NCR) وطلبات حل المشكلات في الموقع (SOR).

### 🚀 الميزات الأساسية
* **تتبع الحالات:** مراقبة البنود النشطة، المرفوضة، المتأخرة، وتلك التي تتطلب تصعيداً.
* **التصنيف حسب التخصص:** عرض الرسوم البيانية للتقارير بناءً على التخصص الهندسي.
* **تحليل الأسباب والأولويات:** التعرف الفوري على الأسباب الجذرية للمشكلات (مواد، تنفيذ، تصميم).
* **سجل تفاعلي:** استعراض وفلترة جدول البيانات بشكل ديناميكي مرن.

### 📋 تصنيف أولويات المشكلات
يتم تصنيف البنود داخل لوحة التحكم بناءً على درجة خطورتها:
* **حرجة (Critical):** مخاطر إنشائية، أو تتعلق بالسلامة والحرائق، أو تعطل التشغيل (مثل: قطع حديد التسليح).
* **عالية (High):** مخالفة كبرى لشروط التعاقد، المواصفات، أو الكود الهندسي (مثل: دفان غير مطابق).
* **متوسطة (Medium):** حيود عن المخططات يمكن إصلاحه دون التأثير على الجدول الزمني (مثل: تسريب زيت طفيف).
* **منخفضة (Low):** مشكلات جمالية أو نقص في التوثيق والمستندات فقط (مثل: نقص الملصقات التعريفية).
